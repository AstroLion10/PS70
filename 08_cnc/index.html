<div class="textcontainer"> <p class="margin"> </p> <h3>Week 8: CNC Milling</h3> <h4>Chocolate Mold</h4> <p class="margin"> For this week's assignment, I created a custom chocolate mold. To begin, I found 3D shapes I wanted to incorporate on cults3d.com (attributions at bottom of page). I imported these shapes into a Fusion file. </p> <image style = "width: 50%"src = "../08_cnc/wk8Imports.png" alt = "Imported Shapes"> </image> <p class="margin"> Then, I created a sketch for the base of the mold. </p> <image style = "width: 50%"src = "../08_cnc/wk8baseSketch.png" alt = "Base Sketch"> </image> <p class="margin"> I extruded this sketch to create the main body. </p> <image style = "width: 50%"src = "../08_cnc/wk8MoldBase.png" alt = "Mold Base"> </image> <p class="margin"> After that, I began to resize and position the imported shapes inside the mold's main body. I ensured the shapes would take up positive space, because since I planned on CNC milling a mold for a silicon mold, the positive space shapes in this mold would be in the correct orientation for the silicon mold. </p> <image style = "width: 50%"src = "../08_cnc/wk8AssembleShapes1.png" alt = "Rocket, Column, and Leaf"> </image> <p class="margin"> I realized that when I scaled the rocket and the column down, they would be too thin to make a solid chocolate truffle that is not prone to breaking. So I added solid bases under these shapes to give them a stronger structure. </p> <image style = "width: 50%"src = "../08_cnc/wk8SmallShapeBases.png" alt = "Bases for Rocket and Column Molds"> </image> <p class="margin"> I decided to add one more mold shape inspired by ocean waves. To create this, I extruded a cylinder inside of the base of the mold and then created a sketch of the waves using the spline tool. I extrude this into the cylinder and used the cut feature. Below is a photo of the full mold model: </p> <image style = "width: 50%"src = "../08_cnc/wk8FinishedMoldModel.png" alt = "Full Mold Model"> </image> <p class="margin"> Now for the fabrication of the mold. I realized that we did not have large feed stock thick enough to CNC mill the mold in one go, so I split the mold into layers that I would later combine and use the vacuum former to get a food-safe shape to cast the silicon in (Tolu's idea). Below are the three layers I split in Fusion: </p> <image style = "width: 50%"src = "../08_cnc/wk83DLayer3.png" alt = "Mold Top Layer Model"> </image> <br></br> <image style = "width: 50%"src = "../08_cnc/wk83DLayer2.png" alt = "Mold Middle Layer Model"> </image> <br></br> <image style = "width: 50%"src = "../08_cnc/wk83DLayer1.png" alt = "Mold Bottom Layer Model"> </image> <p class="margin"> I planned to cut the outlines of the three layers on the ShopBot and then add more details to the second layer with the SRM-20, but I realized that it would be more efficient (and easier to capture the fine details of the molds) by 3D-printing the chocolate shapes and placing them on the mold base before using the vacuum former. </p> <br></br> <image style = "width: 50%"src = "../08_cnc/wk8CNCmill.jpg" alt = "CNC Mill"> </image> <p class="margin"> After milling the layer outlines, I joined them together with double-sided tape. </p> <br></br> <image style = "width: 50%"src = "../08_cnc/wk8CutLayers.jpg" alt = "Cut Layers"> </image> <br></br> <image style = "width: 50%"src = "../08_cnc/wk8Tape.jpg" alt = "Taped Layer"> </image> <br></br> <image style = "width: 50%"src = "../08_cnc/wk8AssembledPhysicalMoldBody.jpg" alt = "Assembled Physical Mold Base"> </image> <p class="margin"> Then, I arranged the 3D shapes inside the mold bases. I made two bases so that there would be enough space between the shapes. </p> <br></br> <image style = "width: 50%"src = "../08_cnc/wk83DprintPhysicalInsideMold.jpg" alt = "Physical Mold Assembly"> </image> <p class="margin"> I placed the mold inside the vacuum former; and after trial and error, I had a successful mold! </p> <br></br> <image style = "width: 50%"src = "../08_cnc/wk8HeatPress.jpg" alt = "Vacuum Former"> </image> <p class="margin"> Below is the fully-vacuum-formed mold: </p> <br></br> <image style = "width: 50%"src = "../08_cnc/wk8VacuumFormedMold.jpg" alt = "Vacuum Formed Mold"> </image> Sources: <br></br> https://cults3d.com/en/3d-model/home/basic-spaceship-silicone-mold-ready-free <br></br> https://cults3d.com/en/3d-model/home/leaf-ice-cube-mold <br></br> https://cults3d.com/en/3d-model/home/spiral-petal-dome-mold <br></br> https://cults3d.com/en/3d-model/architecture/moule-colonne-dorique </p> </div>
