<div class="textcontainer"> <p class="margin"> </p> <h3>Week 8: CNC Milling</h3> <h4>Chocolate Mold</h4> <p class="margin"> For this week's assignment, I created a custom chocolate mold. To begin, I found 3D shapes I wanted to incorporate on cults3d.com (attributions at bottom of page). I imported these shapes into a Fusion file. </p> <image style = "width: 50%"src = "../08_cnc/wk8Imports.png" alt = "Imported Shapes"> </image> <p class="margin"> Then, I created a sketch for the base of the mold. </p> <image style = "width: 50%"src = "../08_cnc/wk8baseSketch.png" alt = "Base Sketch"> </image> <p class="margin"> I extruded this sketch to create the main body. </p> <image style = "width: 50%"src = "../08_cnc/wk8MoldBase.png" alt = "Mold Base"> </image> <p class="margin"> After that, I began to resize and position the imported shapes inside the mold's main body. I ensured the shapes would take up positive space, because since I planned on CNC milling a mold for a silicon mold, the positive space shapes in this mold would be in the correct orientation for the silicon mold. </p> <image style = "width: 50%"src = "../08_cnc/wk8AssembleShapes1.png" alt = "Rocket, Column, and Leaf"> </image> <p class="margin"> I realized that when I scaled the rocket and the column down, they would be too thin to make a solid chocolate truffle that is not prone to breaking. So I added solid bases under these shapes to give them a stronger structure. </p> <image style = "width: 50%"src = "../08_cnc/wk8SmallShapeBases.png" alt = "Bases for Rocket and Column Molds"> </image> <p class="margin"> I decided to add one more mold shape inspired by ocean waves. To create this, I extruded a cylinder inside of the base of the mold and then created a sketch of the waves using the spline tool. </p> <image style = "width: 50%"src = "../08_cnc/wk8Imports.png" alt = "Imported Shapes"> </image> <p class="margin"> </p> <p class="margin"> </p> <p class="margin"> Sources: <br></br> https://cults3d.com/en/3d-model/home/basic-spaceship-silicone-mold-ready-free <br></br> https://cults3d.com/en/3d-model/home/leaf-ice-cube-mold <br></br> https://cults3d.com/en/3d-model/home/spiral-petal-dome-mold <br></br> https://cults3d.com/en/3d-model/architecture/moule-colonne-dorique <br></br> <br></br> <br></br> </p> </div>
