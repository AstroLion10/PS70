<div class="textcontainer"> <p class="margin"></p> <h3>Final Project: Initial Sensing System for Assistive Exoskeleton Glove for Astronauts</h3> <p class="margin"> For my final project, I created a wearable sensing glove that can be used to approximate finger bending angles in order to work towards creating a full soft robotic assistive astronaut glove. A fully integrated sensing glove is crucial in order to give adequate feedback, motion and pressure sensing, and movement signals to the soft robotic components in order to trigger coordinated actuation. </p> <p class="margin">Soft Robotic Glove 3D Model Images:</p> <image style = "width: 50%"src = "../13_finalproject/Screenshot 2025-10-09 115312.png" alt = "Model Image 1"> </image> <br></br><image style = "width: 50%"src = "../13_finalproject/Screenshot 2025-10-09 115331.png" alt = "Model Image 2"> </image> <p class="margin"> <br></br>3D Model Download: <a download href='../13_finalproject/Soft_Robotic_Glove_Model.stl'> Soft Robotic Actuators </a> </p> <p class="margin">Fabrication Process:</p> <p class="margin"> To fabricate the initial sensing components for the soft robotic glove, I first started by making five velostat sensors, one for each finger. I gathered my initial materials and tools: copper tape, velostat, scotch tape, scissors, and conductive steel thread. </p> <image style = "width: 50%"src = "../13_finalproject/fpInitialMaterialsE.jpg" alt = "Model Image 1"> </image> <p class="margin"> Then, I trimmed the velostat to adequate lengths for each of the fingers, and layered a slightly smaller piece of copper tape on each side. </p> <image style = "width: 50%"src = "../13_finalproject/fpSensorsOne.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsTwo.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsThree.jpg" alt = "Model Image 1"> </image> <p class="margin"> After this, I added conductive steel thread on each side of the copper and bound it to the sensor using scotch tape, which would provide insulation. </p> <image style = "width: 50%"src = "../13_finalproject/fpSensorsFour.jpg" alt = "Model Image 1"> </image> <p class="margin"> Then, I attached the sensors to the fabric glove using dots of hot glue and sewed the copper thread towards the wrist. </p> <image style = "width: 50%"src = "../13_finalproject/fpSensorsFive.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsSix.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsSeven.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsEight.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsNine.jpg" alt = "Model Image 1"> </image> <p class="margin"> Then, I cut a solder board with the vertical bandsaw, and meticulously threaded the steel threads to holes in the board. This took hours to complete. </p> <image style = "width: 50%"src = "../13_finalproject/fpThreadTen.jpg" alt = "Model Image 1"> </image> <p class="margin"> To add the electronics, I then soldered the needed wires to the eight sensor ports. </p> <image style = "width: 50%"src = "../13_finalproject/fpSolder.jpg" alt = "Model Image 1"> </image> <p class="margin"> Lastly, I connected the wires to the circuit board using a voltage divider electronics structure with one hundred ohm resistors.
