<div class="textcontainer"> <p class="margin"></p> <h3>Final Project: Initial Sensing System for Assistive Exoskeleton Glove for Astronauts</h3> <h4>Demo Video: <a href="https://youtu.be/CgMXPvm5mTw?si=gArcHX8leupdMDsy">https://youtu.be/CgMXPvm5mTw?si=gArcHX8leupdMDsy</a></h4> <image style = "width: 50%"src = "../13_finalproject/PS70FinalFront.png" alt = "Thumbs Up"> </image> <p class="margin"> For my final project, I created a wearable sensing glove that can be used to classify finger bending in order to work towards creating a full soft robotic assistive astronaut glove. A fully integrated sensing glove is crucial in order to give adequate feedback, motion and pressure sensing, and movement signals to the soft robotic components in order to trigger coordinated actuation. This glove is one step towards this, enabling finger bending characterization to classify hand positions. Below is a 3D Model of what one option for soft robotic actuation could look like. </p> <p class="margin">Soft Robotic Glove 3D Model Images:</p> <image style = "width: 50%"src = "../13_finalproject/Screenshot 2025-10-09 115312.png" alt = "Model Image 1"> </image> <br></br><image style = "width: 50%"src = "../13_finalproject/Screenshot 2025-10-09 115331.png" alt = "Model Image 2"> </image> <p class="margin"> <br></br>3D Model Download: <a download href='../13_finalproject/Soft_Robotic_Glove_Model.stl'> Soft Robotic Actuators </a> </p> <p class="margin">Fabrication Process:</p> <p class="margin"> To fabricate the initial sensing components for the soft robotic glove, I first started by making five velostat sensors, one for each finger. I gathered my initial materials and tools: copper tape, velostat, scotch tape, scissors, and conductive steel thread. </p> <image style = "width: 50%"src = "../13_finalproject/fpInitialMaterialsE.jpg" alt = "Model Image 1"> </image> <p class="margin"> I trimmed the velostat to adequate lengths for each of the fingers, and layered a slightly smaller piece of copper tape on each side. </p> <image style = "width: 50%"src = "../13_finalproject/fpSensorsOne.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsTwo.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsThree.jpg" alt = "Model Image 1"> </image> <p class="margin"> After this, I added conductive steel thread on each side of the copper and bound it to the sensor using scotch tape, which would provide insulation. The full details and instructions reference for creating velostat sensors from Luc's Tech Blog are linked in my <a href="../06_inputs/index.html">Week 6 documentation</a>. </p> <image style = "width: 50%"src = "../13_finalproject/fpSensorsFour.jpg" alt = "Model Image 1"> </image> <p class="margin"> I attached the sensors to the fabric glove using dots of hot glue and sewed the copper thread towards the wrist. </p> <image style = "width: 50%"src = "../13_finalproject/fpSensorsFive.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsSix.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsSeven.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsEight.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpSensorsNine.jpg" alt = "Model Image 1"> </image> <p class="margin"> Then, I cut a solder board with the vertical bandsaw, and threaded the steel threads to holes in the board. This took a couple hours to complete. </p> <image style = "width: 50%"src = "../13_finalproject/fpThreadTen.jpg" alt = "Model Image 1"> </image> <p class="margin"> To add the electronics, I then soldered the needed wires to the ten sensor ports. </p> <image style = "width: 50%"src = "../13_finalproject/fpSolder.jpg" alt = "Model Image 1"> </image> <p class="margin"> Lastly, I connected the wires to the circuit board using a voltage divider electronics structure with one-hundred-ohm resistors. </p> <image style = "width: 50%"src = "../13_finalproject/fpWiresOne.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpWiresTwo.jpg" alt = "Model Image 1"> </image> <image style = "width: 50%"src = "../13_finalproject/fpWiresThreeFull.jpg" alt = "Model Image 1"> </image> <p class="margin">Below is the initial Arduino code used to test the sensors:</p> <code> <pre> //Returns number related to angle of bend from one velostat bend sensor int updateInterval = 1; They mainly fluctuated during movement. Thus, I had to remove these sensors and create new, smaller ones for the central finger joints. </p> <image style = "width: 50%"src = "../13_finalproject/fpSmallerSensors.jpg" alt = "Smaller Sensors on Glove"> </image> <image style = "width: 50%"src = "../13_finalproject/fpThumbSensorCloseUp.jpg" alt = "Small Sensor Close Up on Glove"> </image> <p class="margin"> After testing the new sensors, they exhibited a measurable change between bent and unbent positions. Thus, I was able to calibrate each and integrate their calibration into the code. After callibrating the fingers, the next step was to write the algorithm for classifying five different hand positions: Hi, Point, Thumbs Up, Okay, and Peace. Once this worked within Arduino, I wired five LED lights to the circuit board and modified the code so that one LED would light up for each hand position: </p> <image style = "width: 50%"src = "../13_finalproject/fpLEDsTest.jpg" alt = "LED's"> </image> <image style = "width: 50%"src = "../13_finalproject/fpGreyGlove.jpg" alt = "Grey Glove"> </image> <p class="margin"> Once the LEDs were tested, all that was left was to create an enclosure for the breadboard with a display and test it.
